- Selection/mating operators (tournament/roulette, crossover, mutation,
  elitism) → growth triggers (persistent error/demand/uncertainty) +
  routing/retraining/reuse-before-birth + hysteresis/cooldowns. REJECT
  blind recombination as a default (unvalidated mixing); PERMIT any
  construction technique — distillation, weight averaging, crossover,
  composition, synthesis — as a candidate subject to the same
  validation and acquisition gate. What is prohibited is unvalidated
  acquisition, not any technique. R2b (0.21–0.26x cost, retention
  FAIL) constrains what mating claims must prove, not which methods

  phase) → shared genome (architectures/ports/init/rules/limits, not a
  solution) with initially unspecialized cells; many cells share one
  genome yet diverge. Outcome validated per-cell via manifests, never
  trusted from encoding.
- Open-ended evolution (novelty search, minimal-criterion coevolution,
  POET env-agent pairs) → bounded exploration reserve + J(G) caps ONLY.
  Scope statement, not a theorem: Doc 11 is explicitly bounded/gated by
  design, so THIS track makes no open-endedness claim — but bounded
  resources alone do not prove open-ended development impossible in
  general, and no such rejection is warranted. Claiming open-endedness
