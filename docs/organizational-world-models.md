The adopted direction is to learn reusable, scoped predictions of how changes
affect acquisition, retention and repair. Start with symbolic planning and
guarded case memory, then test learned predictions against equally informed
baselines. Core remains separately adoptable; no new trusted subsystem or
instruction is required. The parser/checked-total example is a lookahead
acceptance case, not proof of learned prediction. Research ambition, model
families and future broader horizons remain open; experiments determine which
strategy earns use.
