# Superseded: original BrainOS CCCM architecture (DOCX)

`BrainOS_CCCM_Architecture.docx` is the project's original architecture
document. It was frozen when the Markdown specification was consolidated
(commit bc116a9) and is kept unchanged as a record of how the design evolved.

**It is not the current specification.** The single canonical framework is
`docs/current/` (start with `docs/current/README.md`); project state is in
`docs/STATUS.md`. Where this document and `docs/current/` disagree,
`docs/current/` governs.
